Subscribe Openly

About

Linking directly to a web feed like an RSS file on your website is not ideal for users.

Browsers like Firefox and Chrome will show the raw XML of your feed.

What if there was a better experience?

With Subscribe Openly, you can link to a URL that will show buttons for all the common feed readers.

When clicked, the button will take the user into a view that lets them subscribe to your feed in their preferred reader.

How To

To use Subscribe Openly, add the following to any links to your web feed on your site:

https://subscribeopenly.net/subscribe/?url=YOUR_FEED_URL

Subscribe Openly doesn't validate or automatically find web feeds, it only generates a link for subscribing to a web feed.

You should make sure the link you provide to Subscribe Openly points to a page with an automatically discoverable web feed, or a specific feed URL.

Choose a Preferred Reader

If you have a preferred reader among those listed on Subscribe Openly, you can move the reader to first in the list of links on your page. To do so, use the following syntax:

https://subscribeopenly.net/subscribe/?url=FEED_URL&prefer=reader_name

Where reader_name is the name of a reader supported by Subscribe Openly, in all lowercase, and without spaces. Here is an example:

https://subscribeopenly.net/subscribe/?url=https://jamesg.blog&prefer=newsblur

Open the example with Newsblur as the preferred reader.
